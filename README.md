# Adrián González Chico — Portfolio

Astro + React + TypeScript + Tailwind CSS. Sitio estático en español.

## Desarrollo

```sh
npm install
npm run dev
```

## Validación

```sh
npm run check
npm run build
```

El contenido de proyectos está en `src/data/projects.ts`. La portada y secciones están en `src/pages/index.astro`. Las animaciones respetan movimiento reducido y utilizan scroll nativo. Las vistas de proyectos son representaciones conceptuales, identificadas como tales, no capturas reales. No se publica el CV largo. Añadir el CV breve cuando esté disponible.
